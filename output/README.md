# Historical output location

The old fitted models, row predictions, SHAP files, notebook and result figures
belong to the preserved `legacy-ml-2026-10-25` version. They have been removed
from the active tree so they cannot be mistaken for revised-model evidence.

Use [research/reports/](../research/reports/README.md) for exact current evidence,
[report/](../report/README.md) for report-ready exports and
[notebooks/](../notebooks/README.md) for cached-result review. Private new scores
belong under `.local_data/`, not this directory.
