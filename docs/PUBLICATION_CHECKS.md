# Publication and acceptance record

Current checks are documented in [integration acceptance](integration/acceptance.md).
The original publication checks remain at the preserved legacy tag and describe
old models, paths and metrics, not the revised active pipeline.

The current workflow checks frozen source/configuration/reference hashes, exact
final aggregate bytes, 290 numerical claim paths, six summary CSV tables, links,
preserved source inputs, cached-map provenance, notebook execution and public
content boundaries. Synthetic tests cover scientific guards and application
behaviour. Default CI never trains on real data or evaluates final labels.

Old verification regenerated UBJ files before checking them. The current
compatibility command is read-only, and optional inference checks supplied model
bytes before loading. Missing/corrupt files fail without export or repair.

Private revised model weights, final row predictions and new local outputs remain
ignored. Existing public source inputs retain their bytes and provenance. The
recorded release still contains one evaluation and one test CSV read; cached
display, map drawing and notebook replay are not further evaluations.

Automated checks and visual PDF review do not substitute for member understanding,
source/licence confirmation, literature review, stakeholder consultation or final
submission approval. No completed human review is inferred from a passing check.
