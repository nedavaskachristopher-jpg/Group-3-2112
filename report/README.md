The group draft integrates framing, supplied data lineage, related-work context,
unchanged ML methods/findings, a first-date cached-score map, recommendations and
an assistance/review appendix. It is review-ready material, not a declaration of
completed member approval or final assessment submission. Confirm author details,
official course requirements and data/domain interpretation before submission.

All ML measured values come from existing public aggregates. The map uses the
original private saved-score cache without a new prediction pass or outcome-based
date selection. Old SHAP and maps are historical, not current-model evidence.
The study did not achieve reliable warning performance or calibrated probabilities.

The PDF reading drafts are rendered and visually checked. LaTeX sources are
provided for template integration; compile and check the chosen group/template
layout separately. Numerical provenance and current file hashes are under
[docs/evidence/](../docs/README.md).
